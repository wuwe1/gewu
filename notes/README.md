# 笔记

原子笔记：一条只讲一件事，用自己的话写。写不出来的地方，就是还没懂的地方。

## 规矩

- 一个文件一条，文件名是短的 kebab-case 英文或拼音，例 `bond-price-vs-yield.md`
- 标题是一句话：一个**主张**（「债券价格和收益率反向变动」）或一个**概念**（「股权风险溢价」）
- 正文几段以内，超过了就拆
- 底下三行，有就写：

```md
# 债券价格和收益率反向变动

（用自己的话：是什么、为什么、举个例子）

- 连到：[[risk-free-rate]]、[[dividend-yield]]
- 从哪来：批次 2026-10-02-demo 的麦当劳那条；读了 《……》第 3 章
- 还不懂：……
```

`[[名字]]` 指向另一条笔记的文件名（不带 .md），还没写的也可以先链上，等于记下一条待写的。
