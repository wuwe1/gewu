# 笔记

用 Obsidian 看（这个目录就是一个库）。公式用 `$…$` 和 `$$…$$`。

## 卡片：一个术语一张

- **文件名就是术语**，照出处的写法：`Expected value.md`、`Axioms of probability.md`
- **内容照抄出处的原文**，不改写；属于一起的放一张（例：公理 1、2、3 都在 `Axioms of probability` 里）
- **原文里出现别的术语，就在那个词上加链接**：`For each [[Event|event]] E…`，`Event` 里再链到 `[[Sample space|sample space]]`。关系顺着定义长出来，不用另写「相关」
- 定义和公式不涉及理解，可以搬（Claude 也可以搬）；只放定义和公式本身，不加属性和标签

## 地图（`maps/`）

每学一个主题，先列一张地图：要弄懂哪些概念、怎么排、各自用来解释什么。节点用 `[[术语]]` 指向卡片；同一个术语在几张地图里指向的是同一张卡片，地图合起来就是整个知识体系。还没写的 `[[术语]]`，就是还没搬或还没学的。

## 图（`figures/`）

TikZ 画：源文件 `figures/<名字>.tex`，`scripts/fig.sh` 编译成同名 `.svg`（文字转成路径，直接显示），卡片里用 `![[<名字>.svg]]` 嵌入，可以加宽度 `![[<名字>.svg|600]]`。`.tex` 和 `.svg` 都进 git。
